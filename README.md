## Overview

Express Scribe provides a desktop environment for transcription tasks that depend on accurate, convenient audio handling. Its Windows workflow combines dictation playback, fast recording navigation, and controls that let users switch between listening and typing while retaining the surrounding context.

The software can be used for personal transcription as well as office-based audio review. Tools such as bookmarks, timestamps, adjustable playback, and repeated navigation help make lengthy recordings easier to work through.

## Transcription Workflow

A standard session can be organized as follows:

1. Import an audio recording or designate a directory for monitoring.
2. Select a playback speed that suits the recording and your working pace.
3. Add timestamps and bookmarks to identify important points.
4. Configure foot-pedal controls or keyboard shortcuts for pausing, rewinding, and resuming playback.
5. Export the completed transcript or other output using the required format.

Helpful workflow options include:

- Navigate quickly between active portions of a recording with the waveform view.
- Turn on multi-channel separation for recordings containing multiple speaker sources.
- Leave backup automation enabled when you want working files copied at regular intervals.

**Can a foot pedal be used to control playback?**  
Yes. Foot pedal mapping allows playback commands to be assigned to compatible hardware controls.

**Where does the application keep its settings?**  
Depending on the setup, preferences are usually held in the application configuration or within local Windows profile locations.

**What should I check if audio will not import or play?**
